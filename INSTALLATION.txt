已经安装的同学

1. 打开超级学霸，进入“设置 → 关于 → 检查更新”，或顶部“核心 → 检查更新”。
2. 发现新版后点击“下载并更新”。下载和安装进度以窗口实际显示为准；下载阶段可以取消。
3. 校验和安装时保持电脑开启。如果提示“重新打开完成更新”，先结束正在进行的学习或通话，再点击该按钮。
4. 重开后再次检查，应显示“已是最新版本”。正常更新保留原有聊天、学习资料、阅读记录、API Key 和设置，无需卸载重装。
5. 本批核心包含既有题库与新题目图，大小以更新窗口为准。同版本重复检查不会重新下载；现有更新器尚未跨不同核心包复用题库文件，因此不能把新图包自身的大小当成整个更新包大小。缺少兼容运行环境的旧电脑，可能由更新入口另行下载一次较大的环境。
6. 如果失败，记下窗口的完整错误提示再重试。不要删除学习目录，不要为解决更新问题反复卸载。正常更新入口以已正式发布的版本为准；源码或验证快照本身不会切换更新入口。

第一次安装：请从同一个版本页面下载整套文件

Windows 64 位：
将以下五个文件放在同一文件夹，再双击 Setup.exe：
Kaixin-Super-Scholar-Windows-v1.7.1-Setup.exe
Kaixin-Super-Scholar-Windows-v1.7.1-Runtime.001
Kaixin-Super-Scholar-Windows-v1.7.1-Runtime.002
Kaixin-Super-Scholar-Windows-v1.7.1-Runtime.003
Kaixin-Super-Scholar-Windows-v1.7.1-Runtime.004
如果下载的是完整 ZIP，先全部解压，再运行其中的 Setup.exe。Windows 文件名保持固定，请勿混用不同版本页面或旧文件夹里的 Setup 与 Runtime 分卷。

Intel Mac：
主镜像：Kaixin-Super-Scholar-MacOS-Intel-v1.7.1-20261117-k12-2-part.dmg
另将同名的 -part.002.dmgpart、-part.003.dmgpart、-part.004.dmgpart 全部下载到同一文件夹。
打开主镜像 -part.dmg，把“开心动力超级学霸”复制到“应用程序”，再从“应用程序”启动。

Apple 芯片 Mac（M 系列）：
主镜像：Kaixin-Super-Scholar-MacOS-Apple-Silicon-v1.7.1-20261117-k12-2-part.dmg
另将同名的 -part.002.dmgpart、-part.003.dmgpart、-part.004.dmgpart 全部下载到同一文件夹。
打开主镜像 -part.dmg，把“开心动力超级学霸”复制到“应用程序”，再从“应用程序”启动。

不要逐个打开 .dmgpart 分卷，也不要把 Intel 与 Apple-Silicon 的分卷混在一起。完整安装包应包含同批当前核心；本批新装与后续“检查更新”是配套的入口，不需要拼接多个日常补丁。

下载或更新需要能访问 GitHub 的发布资源，不需要填写 GitHub Token。速度取决于当前网络和实际下载大小。
更新只替换应用及经过签名校验的运行核心，不删除原有学习目录。
