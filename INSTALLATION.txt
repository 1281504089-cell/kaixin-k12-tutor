开心动力超级学霸 · 安装与更新说明（2026-11-15）

已安装：
1. 打开超级学霸，进入“设置 → 关于 → 检查更新”，或顶部“核心 → 检查更新”。
2. 发现新版本后点击“下载并更新”。窗口显示阶段、大小及进度，下载阶段可取消重试。
3. 校验和安装时不要关闭电脑。若出现“重新打开完成更新”，先结束正在进行的学习或通话，再点击此按钮。
4. 完成后再次检查应显示“已是最新版本”。聊天记录、教材、资料和 API 设置保留，无需卸载。
5. 日常核心为小包更新。早期未补齐运行环境的电脑可能自动下载一次较大的兼容环境；后续使用匹配的小包。
6. 若更新失败，记录窗口的错误提示；不用删除学习数据或反复卸载。网络无响应会给出重试结果，重新联网后再检查即可。

首次安装：
Windows 64 位：将 Setup.exe 与 Runtime.001、.002、.003、.004 放在同一文件夹，运行 Setup.exe。完整 ZIP 需先全部解压，再运行 Setup。
Intel Mac：下载 Intel 的全部 DMG 分卷到同一文件夹，打开不带 .002/.003/.004 的主 DMG，把应用复制到“应用程序”。
Apple 芯片 Mac：使用 Apple-Silicon 的对应全部 DMG 分卷，按同样方式安装。
U 盘的普通单文件 DMG 可直接打开；无需把它与 GitHub 分卷混用。

更新时仅替换应用和经过签名校验的运行核心；不删除原有学习目录。
网页打不开或网络有限制时，先检查当前网络是否能访问 GitHub 的更新资源；无需在设置中填写 GitHub Token。
