开心动力超级学霸：Mac 语音连接组件修复（2026-11-12）

适用：已经安装并启动过的 Intel Mac 或 Apple 芯片 Mac 客户端。
用途：补齐系统 SOCKS 代理所需的 python-socks 3.2.1。原完整安装包漏带了该组件，部分电脑会在开始通话时直接断开。

操作：
1. 完全退出开心动力超级学霸。
2. 保持本文件夹内的文件在一起，双击“修复语音连接.command”。
3. 看到“语音代理组件已补齐”后，重新打开客户端并点击“开始通话”。

修复全程离线，无需管理员密码，无需重新下载教材或完整安装包。
只向客户端自带的 Python 安装经过 SHA256 校验的组件，不更改学习记录、教材、已保存的 Key 和系统代理设置。
这是针对已确认的安装包组件遗漏的小修复，不代表所有通话中断都由它造成。
如仍断开，需要查看出问题电脑的 runtime.log；本轮尚未在该台 M4 上复测。
