# 开心动力超级学霸

开心动力超级学霸是一款面向学生的中文桌面学习应用。可以带着作业问老师，打开教材边读边问，也可以把讲义和试卷存下来，下次接着用。

- 想听讲解，点回答下方的朗读。想和老师边说边聊，用语音通话。要给老师看纸上的题，用高拍仪。
- 想安排复习，从聊天里的「规划」开始。错题、笔记、日历和任务看板都在左侧工作台。

## 本批变化

- 数学和物理配图共用已核对的图库与可变参模板。补齐多类静态图和可拖动的动态图。
- 题库按学生语义检索，普通要题使用一秒快检。同一聊天避免重复出题，并可在右栏查看原题和出处。
- 对话右栏支持「边读边问」和「互动实验」。同一轮讲解可同时展示已核对的图形和教材实验。
- 修复旧版 Intel Mac 的启动器重开。Windows、Intel Mac、Apple 芯片 Mac 都通过新装、应用内升级、重开和回退验收。
