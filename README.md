# 开心动力超级学霸

开心动力超级学霸是一款面向学生的中文桌面学习应用。可以带着作业问老师，打开教材边读边问，也可以把讲义和试卷存下来，下次接着用。

- 想听讲解，点回答下方的朗读。想和老师边说边聊，用语音通话。要给老师看纸上的题，用高拍仪。
- 想安排复习，从聊天里的「规划」开始。错题、笔记、日历和任务看板都在左侧工作台。
