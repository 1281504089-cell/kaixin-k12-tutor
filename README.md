如果 Mac 提示镜像无法识别或错误 109、110，先核对本平台整组分卷是否下载齐全、同批且未改名。首次来源确认出现“身份不明的开发者”时，确认文件来源后，按系统“隐私与安全性”的提示处理。[Apple 说明](https://support.apple.com/zh-cn/102445)

## 已安装学生原地更新

正常入口统一为 **“核心 → 检查更新”**或**“设置 → 关于 → 检查更新”**，无需卸载重装或删除学习目录。

1. 发现正式新版后点击“下载并更新”，核对窗口显示的大小与进度，保持电脑开启。下载阶段可以取消；安装和备份以窗口提示为准。
2. 若提示“重新打开完成更新”，先结束正在进行的学习或通话，再点击该按钮。只关闭窗口不等于完全退出软件。
3. 重开后核对完整构建，再检查一次应显示已是最新。正常更新保留聊天、任务、教材、资料、阅读记录、设置及 Key。
4. 缺少兼容原生环境的早期安装可能另行下载较大的兼容环境，不能把题页增量体积当整个更新大小。旧更新器需先成功取得一次更新，才会获得新的恢复逻辑；持续断网、磁盘错误或系统终止仍可能使更新失败。
5. 在线反复失败时保留完整错误与日志，再使用经过同批校验、适用当前系统的离线更新。不要串装旧补丁、运行历史 `00` 匹配脚本或自行修改环境编号。只有最早启动器本身无法检查更新时，才按适用版本的[历史迁移说明](MIGRATE-LEGACY.md)处理；不要把一次迁移当成长期更新流程。

更新和下载需要能够访问 GitHub 发布资源，不需要填写 GitHub Token。U 盘离线更新不需要重新下载文件；学习中调用在线模型仍需要联网。核心、启动器和原生环境分别校验，源码提交或候选构建本身不会改变已安装客户端的正式更新入口。历史发行保留，供维护者核对和回退。

| 教材随读随问 | 按学段、学科筛选或搜索年级、册名，打开整册原页。划选文字可标注或提问。遇到公式、图形和扫描页，长按原页选择「截图引用」，拖框后把原图加入笔记或引用到提问。翻页后可在同一阅读会话继续追问。 |
| 聊天内边读边问 | 在输入框上方点「边读边问」，在右侧打开教材、资料库文档或临时附件。点「问当前页」，把这一页和问题放在同一个聊天里继续讨论。 |
| 实时语音通话 | 在「设置 → 语音」选豆包或 MOSS-Live 并保存对应 Key。点聊天右上角的电话，有已保存 Key 时直接接通；首次也可在通话窗口填写。可切换学习辅导、英语陪练、口语翻译、模拟面试等场景，也可共享窗口或屏幕。收起浮窗后可以从「通话中」重新打开，挂断后文字保存到原对话。 |
| 高拍仪辅导 | 点输入框上方的「高拍仪辅导员」，再点「开始通话」（部分版本显示「开始语音通话」），把纸面题对准摄像头。可旋转、镜像、调画面比例，或临时切到共享屏幕。做题时先给提示，明确要答案时会给简短讲解。 |
| 九科学习项目 | 语文、数学、英语、物理、化学、生物、历史、地理、政治各默认保留一个「错题讲解」。点科目旁的「＋」在本科目新建普通对话，自动带上对应老师；项目指令和对话指令仍分别设置。 |
| 拍题与资料问答 | 拍照和一至两页的短 PDF 可交给支持读图的模型先看原图。需要全文时在后台解析。上传时可选临时使用或长期保存。输入框和右侧共用原件，先阅读和提问，后台再准备全文；长期资料在「资料 → 资料库」找回。 |
| 错题本与笔记 | 按学科保存错题，选中文字或截取公式和图形后可加入笔记。 |
| 九科学习复盘 | 选学科和日期，默认读取对应科目项目，也可手动加入聊天或阅读对话。报告按学科整理考点、易错点和练习，理科按需配图，依据放在文末，可导出 Word。「四问复盘」选填。 |
| 选模型 | 菜单标出快速问答、理科难题验算、长文阅读等用途。填入 API 后可发现接口列出的受支持模型，打开菜单时在后台更新列表。 |
| 数学动画和视频讲解 | 发送后后台生成，可以继续其他学习。从「动画与视频」看进度、停止指定任务或回到原聊天播放。 |
| 其他学习工具 | 支持公式、图表、互动课件、日历和任务看板。安装包附带本机语音转文字和向量检索组件。 |

教材库收录的是当前目录中的主科册次。原页可直接阅读；普通讲解由模型主讲，相关已核对教材要点可作为侧栏对照。明确引用、边读边问保留实际所读内容与跳转，待核对页面保留状态。

「资料库」保存可直接阅读的原件；「知识库」建立可供 AI 检索的内容索引。选择长期保存时会自动加入本机知识库，无需学生另做一次导入。

学习记录、资料和设置保存在本机。语音通话和高拍仪辅导需要联网，可在「设置 → 语音」提前保存豆包或 MOSS-Live API Key；首次通话时填写的 Key 也会在接通后保存。两个服务分别保存 Key，独立于聊天模型及本机语音转文字。远程模型问答、Edge 朗读、搜索和公开视频字幕也需要网络。安装包已排除 API 密钥、个人学习记录和签名私钥。
