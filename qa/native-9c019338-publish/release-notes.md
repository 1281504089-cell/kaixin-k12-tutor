### 教学配图更新

- 已核对的画板图和教学插画跟在相应讲解段落后，重开历史可以继续查看。
- 生图失败时，讲解照常。合适的原图、画板图和学习总结卡会补回原回答。画板画不出时，获准使用的千问示意图也先审核。
- 只讲关系的示意图允许近似。数据、角标、公式、方向和题设尺度仍要核对。
- 新建百炼文生图配置，默认推荐 qwen-image-2.1-turbo。付费服务由用户启用。

已安装的学生可在应用内点「检查更新」。首次安装时，Windows 把 Setup 与所有 Runtime 分卷放在同一目录后打开 Setup。Mac 请选 Intel 或 Apple 芯片对应的一组，下载该组全部分卷后打开第一个 DMG。
