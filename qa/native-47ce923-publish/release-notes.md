# 开心动力超级学霸桌面版

本次更新统一包含数学与物理图库、教材检索、课堂配图、题库和互动实验。源码节点为 `47ce92383c557fb37714ef6c9d470e9ee102bb5f`。

- 讲解和学生明确要图共用图库与参数模板。没有可用图库图时，支持按题设本机绘制并核对。补充函数及球面光路等可复用构造。
- 普通出题会先快查合适原题，同一聊天避免重复。快查超时或无合适题时可直接提供原创题并标明来源。指定资源和只要原题的要求会保留。
- 从题库点「去提问」可开启独立对话，在右侧看到对应题目。右侧工具可直接打开「边读边问」或「互动实验」。
- 讲解可同时附上图形和教材实验。更新物理、化学和地理的实验入口及已核对的教材定位。
- 修复旧版 Intel Mac 完整安装包在重开时签名校验尚未完成就回退的问题。

已安装的学生端可从「核心 → 检查更新」或「设置 → 关于 → 检查更新」安装，按提示重开。新电脑使用对应系统的完整安装文件。Mac 的全部分卷须放在一起，打开首份 `.dmg`。Windows 的 Setup 和四个 Runtime 分卷须保留原文件名并放在同一目录。
