一、已经装好软件，只要更新
不要卸载，不要删除学习文件夹，也不用重新填写 Key。
联网方式：在原软件里点击“检查更新”，按提示确认，等它备份并重新打开。
首次兼容更新可能需要下载运行环境，体积比离线核心小包大；学习记录保留。
离线方式：选对应系统的“原地更新”ZIP，完整解压，按里面的“先看更新步骤.txt”操作。
若已经显示相同或更新的运行核心编号，无需再安装一次。

二、新电脑第一次安装
Windows：解压完整安装 ZIP，保持 Setup.exe 和四个 Runtime 分卷在同一文件夹，再双击 Setup.exe。
从 GitHub 下载时，同样要把 Setup.exe 和对应的全部 Runtime 分卷下载齐；不要只下载 Setup.exe。
Intel Mac：选择 Mac-Intel；Apple 芯片 Mac：选择 Mac-Apple。
U 盘提供单个完整 DMG；打开后把“开心动力超级学霸”拖进“应用程序”，再从“应用程序”打开。
GitHub 的 Mac 映像超过下载大小限制，分为一个 .dmg 和若干 .dmgpart：全部放同一文件夹，只打开第一个 .dmg。
不要打开 .dmgpart，不要把分卷单独拷走。
首次启动要解包自带环境和教材，请等待，不用另装 Python、Node 或 MOSS 插件。
界面首次默认为中文。运行核心编号应包含 20261113-sync2，主版本号仍为 1.7.1。
